# 链接下载器 v0.1.0 🎉

首个 Windows 公测版本，支持将常见媒体链接整理并下载为本地文件。📥

## ✨ 本版本包含

- 🎬 YouTube、TikTok、Instagram、抖音、Bilibili 等平台的链接解析入口
- 🔗 支持网页 URL、短链接，以及抖音 App 的内部分享文案粘贴
- 🧾 展示标题、作者、缩略图、可用格式等媒体信息
- 📦 视频、音频、图片和文案按选择导出
- 🛡️ 本地调用 yt-dlp 与 FFmpeg，减少中间上传环节
- 🌓 中英文界面与明暗主题切换
- 🚀 Windows x64 安装版和便携版

## 🧭 使用方式

1. 下载 `setup-x64.exe` 安装版，或下载 `portable-x64.exe` 直接运行。
2. 粘贴媒体链接或抖音分享文案。
3. 点击“解析链接”，确认媒体信息和导出格式。
4. 选择保存目录并开始下载。✅

## ⚠️ 使用边界

请仅下载你拥有权利或已获授权的内容，并遵守所在地区法律、平台规则和版权要求。本项目不绕过付费、访问控制或其他技术保护措施。🔐

## 🧰 说明

安装包已内置对应版本的 `yt-dlp.exe` 与 `ffmpeg.exe`，不需要用户额外配置。平台网页接口会变化，个别需要登录、Cookie 或风控验证的内容可能无法解析。🌐
